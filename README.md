# Исследование клавиатурного почерка (Keystroke Dynamics Biometrics)

Программный комплекс для сбора, визуализации и анализа динамических биометрических характеристик клавиатурного почерка человека.

Программа разработана в рамках лабораторной работы №1 по дисциплине «Биометрические методы идентификации личности».

---

## 📌 Функциональные возможности

1. Оценка криптографической сложности парольной фразы:
   - Автоматический расчет длины строки (L), мощности используемого алфавита (A), информационной энтропии по формуле Хартли: S = L * log2(A).
   - Оценка полного числа возможных комбинаций для подбора (A^L).

2. Фиксация временных меток ввода:
   - Измерение времени удержания каждой клавиши нажатой (Hold Time / Dwell Time).
   - Измерение латентных интервалов между нажатиями соседних символов (Flight Time / интервал Down-Down).
   - Расчет общей скорости печати (знаков в секунду).

3. Статистический анализ:
   - Расчет выборочного математического ожидания M[X] и дисперсии D[X] скорости ввода.
   - Сравнение статистических показателей в зависимости от времени суток (Утро / День / Вечер / Ночь).

4. Классификация наложений нажатий (Overlaps):
   - Тип 1 (K1 down -> K2 down -> K1 up -> K2 up): классическое перекрытие клавиш при быстром беглом наборе.
   - Тип 2 (K2 down -> K1 down -> K2 up -> K1 up): асинхронный сброс клавиш.
   - Тип 3 (K1 внутри K2): полное нажатие и отпускание одной клавиши внутри интервала удержания другой.

5. Сравнение оборудования:
   - Возможность разделять выборки для различных устройств ввода (встроенная клавиатура ноутбука, мембранная, механическая).

6. Интерактивная визуализация:
   - Вкладка 1: График динамики латентных интервалов перехода между соседними символами.
   - Вкладка 2: Столбчатая гистограмма средней скорости печати с дисперсией по времени суток.
   - Вкладка 3: Длительность удержания каждой клавиши фразы.
   - Вкладка 4: Диаграмма распределения зарегистрированных типов наложений.

## 🛠 Стек технологий и требования

- Язык разработки: Python 3.8+
- Графический интерфейс (GUI): tkinter (входит в стандартную библиотеку Python).
- Сторонние зависимости: Отсутствуют. Все расчеты и графики отрисовываются нативно через tkinter.Canvas, поэтому программа не требует установки сторонних библиотек (matplotlib, numpy).

## 🚀 Запуск программы

1. Склонируйте репозиторий или скачайте файл скрипта:

    git clone https://github.com/your-username/keystroke-biometrics.git
    cd keystroke-biometrics

2. Запустите скрипт через стандартный интерпретатор Python:

    python keystroke_biometrics.py

---

## 📖 Инструкция пользователя

1. Задание параметров:
   - В верхней панели введите целевую парольную фразу (по умолчанию: "биометрическая защита информации").
   - Укажите текущее время суток и используемый тип клавиатуры.

2. Ввод попытки:
   - Установите курсор в поле «Поле для набора пароля».
   - Наберите эталонную строку в обычном для себя темпе и нажмите клавишу Enter (или кнопку «Зафиксировать попытку»).
   - Примечание: если фраза набрана с опечаткой, система выдаст предупреждение и очистит строку, чтобы сохранить чистоту биометрической выборки.

3. Просмотр графиков:
   - Переключайтесь между вкладками в нижней части окна: все графики и статистические расчеты обновляются автоматически после каждой зафиксированной попытки.

4. Управление данными:
   - Кнопка «Сбросить ввод» — очищает текущую строку набора.
   - Кнопка «Очистить всю базу» — обнуляет накопленную историю попыток и очищает графики.

## 📐 Архитектура и функции кода

- KeystrokeAnalyzerApp.__init__() — построение графического интерфейса, инициализация структур данных и привязка обработчиков событий мыши и клавиатуры.
- update_phrase_complexity() — динамический расчет мощности алфавита (A) по классам символов (русский/английский алфавит, регистр, цифры, спецсимволы) и вычисление энтропии по формуле Хартли.
- on_key_press() / on_key_release() — перехват аппаратных событий нажатия и отпускания клавиш с миллисекундной фиксацией системного времени (event.time).
- on_submit_attempt() — валидация совпадения текста с эталоном, расчет интегральной скорости ввода и сохранение профиля попытки в общую базу.
- detect_overlaps() — алгоритм классификации взаимного пересечения временных отрезков [down, up] соседних клавиш для выявления наложений 1, 2 и 3 типов.
- redraw_all_canvases() — процедурная отрисовка графиков, сеток, текстовых подписей и столбчатых диаграмм на холстах Canvas.

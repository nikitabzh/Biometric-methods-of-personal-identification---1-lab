# Исследование клавиатурного почерка (Keystroke Dynamics Biometrics)

Программный комплекс для сбора, визуализации и анализа динамических биометрических характеристик клавиатурного почерка человека. 

Программа разработана в рамках лабораторной работы по дисциплине «Биометрические методы идентификации личности».

---

## 📌 Функциональные возможности

1. **Оценка криптографической сложности парольной фразы:**
   - Автоматический расчет длины строки ($L$), мощности алфавита ($A$), информационной энтропии по Хартли ($S = L \cdot \log_2 A$) и сложности полного перебора.
2. **Фиксация временных меток ввода:**
   - Измерение времени удержания каждой клавиши нажатой (**Hold Time** / **Dwell Time**).
   - Измерение латентных интервалов между нажатиями соседних символов (**Flight Time** / **Down-Down**).
   - Расчет общей скорости печати (знаков в секунду).
3. **Статистический анализ:**
   - Расчет выборочного математического ожидания $M[X]$ и дисперсии $D[X]$ скорости ввода.
   - Сравнение статистических показателей в зависимости от времени суток (Утро / День / Вечер / Ночь).
4. **Классификация наложений нажатий (Overlaps):**
   - **Тип 1:** $K_1\downarrow \to K_2\downarrow \to K_1\uparrow \to K_2\uparrow$ (перекрытие клавиш при быстром беглом наборе).
   - **Тип 2:** $K_2\downarrow \to K_1\downarrow \to K_2\uparrow \to K_1\uparrow$ (асинхронный сброс клавиш).
   - **Тип 3:** $K_2\downarrow \to K_1\downarrow \to K_1\uparrow \to K_2\uparrow$ (полное нажатие и отпускание одной клавиши внутри интервала удержания другой).
5. **Сравнение оборудования:**
   - Возможность разделять выборки для различных устройств ввода (встроенная клавиатура ноутбука, мембранная, механическая).
6. **Интерактивная визуализация:**
   - Вкладка 1: График динамики латентных интервалов перехода между клавишами.
   - Вкладка 2: Столбчатая гистограмма средней скорости с доверительными интервалами $D[X]$ по времени суток.
   - Вкладка 3: Длительность удержания каждой клавиши.
   - Вкладка 4: Диаграмма распределения типов наложений.

---

## 🛠 Стек технологий и требования

- **Язык:** Python 3.8+
- **Графический интерфейс (GUI):** `tkinter` (встроен в стандартную библиотеку Python).
- **Сторонние зависимости:** **Отсутствуют**. Все расчеты и графики отрисовываются нативно через `tkinter.Canvas`, поэтому программа не требует установки `matplotlib`, `numpy` или компиляторов C++.
